# React Sample Project

A simple Hello World React application to get started with React development.

## Features

- ✨ Simple and clean UI
- 🚀 Easy to understand
- 📦 Ready to extend
- 🎨 Basic styling included

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Kartheekbalu/react-sample-project.git
cd react-sample-project
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The app will open in your browser at [http://localhost:3000](http://localhost:3000).
